# 물놀이 관리지역 좌표 전수 점검 — 2026-09-10

## 결론

- 행정안전부 생활안전지도 `IF_0044`의 현재 공개 최신본은 **2025년 수집, 2025-07-25 수정본**이다.
  공개 주기는 연 1회이며 2026-09-10 재조회 결과도 **1,336건**이었다.
- API 전 건을 다시 내려받아 기존 원본과 비교했으며 행 수와 내용은 같았다. 즉 단순 재수집만으로는 원본 좌표
  오류가 없어지지 않는다.
- 1,336건 모두를 현재 표시 좌표의 역지오코딩, 공식 주소의 정방향 지오코딩, 행정구역 일치 여부와 거리,
  동일 좌표 반복 여부로 검사했다. 1차 이상 후보 207건은 장소명 검색을 추가로 대조했다.
- 장소명·법정리·교량/계곡 장소점 또는 하천 중심선이 함께 일치하는 **32건을 새로 보정**했다. 기존 현장·공식
  자료로 보정한 2건을 포함해 현재 좌표 보정은 총 **34건**이다.

공식 메타데이터: [생활안전지도 물놀이관리지역](https://www.safemap.go.kr/opna/data/dataViewRenew.do?objtId=122)

## 점검 방법

1. `tools/build_waterplay.py`로 `IF_0044` 전 페이지를 다시 수집하고 API `totalCount`와 실제 행 수를 대조했다.
2. `tools/audit_waterplay_coordinates.py`로 1,336개 표시점 전부를 카카오 좌표→행정구역 변환으로 검사했다.
3. 원본 주소를 카카오 주소 검색점으로 변환해 현재 점과의 거리를 계산했다.
4. 시·군 불일치, 1km 이상 이격, 주소 검색 실패, 서로 다른 장소명이 같은 좌표를 쓰는 행을 장소명으로 재검색했다.
5. 주소가 읍·면까지만 있는 경우 대표점과 실제 관리구간이 다를 수 있으므로 거리만으로 자동 이동시키지 않았다.
   명칭에 법정리·교량·계곡이 명시되고 다른 지도 근거와 함께 맞는 경우만 보정했다.

## 재현·운영 원칙

- 재점검: `python3 tools/audit_waterplay_coordinates.py --keywords`
- 원천 갱신: `python3 tools/build_waterplay.py`
- 빌드는 보정 ID가 최신 원본에서 사라지거나 이름이 달라진 경우, 필수 근거가 없거나 대한민국 범위를 벗어난
  경우 실패한다.
- 카카오 장소점은 현재 위치 검증의 보조 근거다. 관리구간의 법적 범위를 나타내지 않으며, 점 자료를 선·면으로
  확대 해석하지 않는다.
