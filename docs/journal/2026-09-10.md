# 2026-09-10

## 한 일

- 관리자 지형지물 유형에 `🍽️ 식당/카페`를 추가했다.
- 식당/카페는 이름을 필수로 입력하고, 카카오맵에서 공유한 장소 URL을 선택적으로 저장할 수 있게 했다.
- 식당/카페 마커는 일반 사용자도 상세 팝업을 열 수 있다. 팝업에는 이름·메모와 `카카오맵 장소 상세` 링크가 표시된다.
- 카카오맵 URL을 입력하지 않은 경우에도 등록 이름과 좌표를 이용한 카카오맵 위치 링크를 자동 생성한다.
- 외부 링크 오용을 막기 위해 HTTPS의 `map.kakao.com`, `place.map.kakao.com`, `kko.to`만 클라이언트와 Worker에서 허용한다.

## 결정·근거

- 기존 보·여울 등 안전 지형지물은 일반 사용자에게 말풍선을 열지 않는 정책을 유지한다. 장소 정보가 필요한 식당/카페만 공개 상세 팝업을 사용한다.
- 지형지물 저장 형식에 선택 필드 `kakaoUrl`을 추가해 기존 데이터와 호환되게 했다.

## 검증

- `python3 tools/build_map.py`, `python3 tools/build_map.py test`, 생성 HTML 4개의 인라인 JavaScript `node --check`,
  Worker `node --check`와 Wrangler dry-run 번들을 통과했다.
- Playwright 모바일 검증에서 지형지물 유형 9개와 3열 선택 UI, 식당/카페 선택 시 이름·카카오 URL 입력란 표시,
  이름 누락·허용되지 않은 URL 오류 안내, 저장 요청의 `type/name/kakaoUrl`을 확인했다.
- 일반 사용자 상태에서 식당/카페만 상세 팝업을 유지하고 여울은 팝업이 없는 기존 정책, 입력 URL 및 좌표 폴백
  카카오맵 링크, 외부 유사 도메인 거부와 JavaScript 오류 0건을 확인했다.
- Wrangler 로컬 Worker에서 식당/카페 저장·조회는 200, 허용되지 않은 URL과 이름 누락은 각각 400 응답임을 확인했다.
