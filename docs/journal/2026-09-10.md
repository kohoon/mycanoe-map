# 2026-09-10

## 한 일

- 관리자 지형지물 유형에 `🍽️ 식당/카페`를 추가했다.
- 식당/카페는 이름을 필수로 입력하고, 카카오맵에서 공유한 장소 URL을 선택적으로 저장할 수 있게 했다.
- 식당/카페 마커는 일반 사용자도 상세 팝업을 열 수 있다. 팝업에는 이름·메모와 `카카오맵 장소 상세` 링크가 표시된다.
- 카카오맵 URL을 입력하지 않은 경우에도 등록 이름과 좌표를 이용한 카카오맵 위치 링크를 자동 생성한다.
- 외부 링크 오용을 막기 위해 HTTPS의 `map.kakao.com`, `place.map.kakao.com`, `kko.to`만 클라이언트와 Worker에서 허용한다.
- 카카오 API가 반환하는 HTTP 장소 URL이나 HTTP 공유 링크는 허용 도메인을 확인한 뒤 HTTPS로 정규화한다.
- 식당/카페 URL을 비워 저장하면 Worker가 이름과 등록 좌표로 카카오 로컬 키워드 검색을 실행하고, 식당·카페
  결과 중 이름 유사도와 거리가 기준을 통과한 장소의 상세 URL을 자동 저장하도록 확장했다.
- 자동 매칭 결과에는 카카오 장소 ID·실제 장소명·거리·매칭시각을 함께 남기며, 팝업에도 매칭된 이름과 거리를 표시한다.
- 정확히 같은 이름은 3km, 부분·유사 이름은 1.5km 이내로 제한하고, 일치하지 않으면 종전 좌표 링크를 사용한다.
- 자동 연결된 항목을 수정할 때는 기존 자동 URL을 직접입력란에 고정하지 않고, 바뀐 이름·좌표로 다시 검색한다.
  관리자가 직접 입력한 URL은 그대로 유지한다.
- 행정안전부 생활안전지도 물놀이 관리지역 `IF_0044`를 전수 재수집했다. 공개 최신본은 여전히 2025년 수집·
  2025-07-25 수정본 1,336건이며, 2026-09-10 API 응답도 1,336건으로 기존 원본과 같았다.
- 1,336건 모두를 주소 검색점, 현재 좌표의 행정구역, 거리, 같은 좌표 반복 여부로 검사하고 이상 후보 207건은
  장소명 검색을 추가 대조했다.
- 장소명·법정리·교량/계곡 또는 하천 중심선이 함께 확인된 32건을 새로 보정했다. 기존 북벽앞·파서탕을 포함한
  좌표 보정은 총 34건이다. 특히 충주에 있던 배알도공원을 광양으로 옮기고, 한 점에 겹친 양평·철원·인제·단양
  관리지역들을 실제 장소별로 분리했다.
- 좌표 전수 점검 도구와 좌표/근거 회귀 테스트를 추가하고, 데이터 메타에 원천 수정일·최신 확인일·보정 건수를
  기록했다. 상세 보고서는 `docs/waterplay-coordinate-audit-2026-09-10.md`에 남겼다.

## 결정·근거

- 기존 보·여울 등 안전 지형지물은 일반 사용자에게 말풍선을 열지 않는 정책을 유지한다. 장소 정보가 필요한 식당/카페만 공개 상세 팝업을 사용한다.
- 지형지물 저장 형식에 선택 필드 `kakaoUrl`을 추가해 기존 데이터와 호환되게 했다.
- 카카오 장소 ID는 매칭 이력을 추적하기 위한 값일 뿐 현재 영업 상태로 판정하지 않는다. 사용자는 상세 링크에서
  카카오맵의 현재 정보를 확인한다.
- 자동 보 시드용 `weir:` 예외는 유형이 `보`일 때만 허용해, 식당/카페 등록과 카카오 검색은 반드시 관리자 인증 뒤 실행되게 했다.
- 물놀이 주소가 읍·면까지만 제공되는 행은 주소 검색점과 수 km 차이가 나도 오류로 단정하지 않았다. 정확한
  장소명이나 법정리, 실제 교량·계곡·하천 중심선이 함께 맞는 고신뢰 사례만 이동하고 나머지는 원본점을 유지했다.
- 같은 좌표의 여러 ID는 과거/현재 행 또는 상·하류 복수 관리구간일 수 있어 자동 병합하지 않았다. 식별자 존재를
  현재 동일 상태로 해석하지 않고 원본 ID와 관리 속성을 보존했다.
