## 결정·근거

- 자동 휴식은 GPS 오차를 이동으로 잘못 보지 않도록 정확도에 따라 20~45m의 이동 판정 폭을 쓴다. 약 3분 정지 시 자동 휴식, 다시 이동이 2회 연속 확인되면 자동 재개한다.
- 자동 휴식은 탐지 시점이 아니라 정지가 시작된 시각으로 소급해 활동 시간을 보정한다.
- 수동 휴식에서는 GPS watch를 중지해 배터리를 아끼고, 자동 휴식에서는 재이동을 감지해야 하므로 watch를 유지한다.
- 웹 한계를 숨기지 않고 실측과 추정을 선 색과 `약` 표시로 분리했다. 시간은 사용자 요청대로 시작~현재 경과에서 휴식만 제외한다.
- 코스 진행률은 코스 좌표 배열의 방향을 강제하지 않고, 출발 위치와 첫 이동 방향으로 정/역방향을 결정한다.
