- DNS의 `canoe` CNAME을 GitHub Pages에 연결하고 전용 TLS 인증서를 발급받아 HTTPS 강제를 적용했다.
- 기존 루트 도메인의 다른 서비스 설정은 유지했다. `[3a6c5d9]`

## 점검 결과 / 미해결

### 1. 주요 강줄기 검색이 짧게 표시되는 문제

- 원인은 같은 이름의 강이 여러 선분으로 저장돼 있는데 검색 결과는 그중 한 선분만 전달하는 구조다.
- 현재 확인된 영향:

  | 강 | 원본 선분 수 | 검색 첫 결과 | 전체 자료 길이 |
  |---|---:|---:|---:|
  | 낙동강 | 2 | 약 4.4km | 약 478.7km |
  | 금강 | 2 | 약 13.0km | 약 413.1km |
  | 남한강 | 5 | 약 5.1km | 약 225.2km |
  | 영산강 | 3 | 약 0.7km | 약 144.8km |
  | 한강 | 3 | 약 0.9km | 약 89.0km |

- 북한강·섬진강·임진강·소양강·홍천강·동강·평창강 등 단일 선분인 강은 현재 정상이다.
- **아직 수정하지 않았다.** 주요 강은 같은 이름의 모든 선분을 합쳐 보여주되, `남천`·`동천`처럼 전국에 동명이 많은 하천은 지역별로 유지하는 방식이 필요하다.

### 2. 카누 계획용 CCTV 추가 검토

- 수위관측 CCTV 외에 카누 계획에 유용한 공개 CCTV 후보를 검토하기 시작했다.
- 우선 판단 기준은 수면·선착장·진입로가 실제로 보이는지, 촬영 시각과 방향이 있는지, 로그인 없이 안정적으로 열람 가능한지, 지도에 직접 연결 가능한지다.
- 전달받은 ChatGPT 공유 대화는 당시 브라우저 연결 문제로 본문을 읽지 못해 후보 데이터의 채택 여부를 확정하지 못했다.
