## 등록 코스 공유 링크 표시 복구

- 문제: `?course=k...` 형태의 등록 코스 공유 링크로 지도를 열면 코스 이름 팝업과 위치 확대는 동작하지만 코스 선이 보이지 않았다.
- 원인: 일반 지도에서는 로그인 사용자의 코스를 불러와 그리지만, 공유 링크에서는 공개 단건 조회만 하고 그 결과를 지도 레이어에 추가하지 않았다.
- 수정: 공유 조회로 받은 코스를 먼저 지도에 그린 뒤, 해당 코스만 남기고 위치를 확대하도록 순서를 바로잡았다.
- 추가 확인: 비로그인 수신자에게는 코스가 그려져도 전면 로그인 화면이 지도를 가리고 있었다. 코스 ID만으로 허용하지 않고, 공개 조회에서 현재 존재하는 코스로 확인된 경우에만 로그인 화면을 걷어 공유 지도를 볼 수 있게 했다.
- 공유 화면 종료: 공유 코스를 본 뒤 일반 지도로 넘어갈 수 있도록 왼쪽에 코스명과 `코스 OFF` 버튼을 추가했다. 버튼은 모바일에서 코스명을 가리지 않도록 짧게 표시하고, 로그인 사용자는 일반 지도 상태로 전환되며 비로그인 사용자는 로그인 화면으로 돌아간다.
- 영향 범위: 등록 코스 공유 링크만 수정했다. 정적 추천 코스 공유, 일반 지도 진입, 코스 소유권과 수정·삭제 권한은 바꾸지 않았다.

## 검증

- 문제를 제보받은 `k1786952751323` 코스의 공개 API가 47개 경로 좌표를 정상 반환함을 확인했다.
- 로컬 운영 빌드의 동일 공유 URL에서 외곽선·본선·클릭 영역이 모두 지도에 표시됐다.
- 코스명, 약 20.21km 팝업, 자동 확대를 확인했다.
- Headless Chromium에서 JavaScript 오류가 발생하지 않았다.
